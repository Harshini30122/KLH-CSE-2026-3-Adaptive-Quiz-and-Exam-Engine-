Project Abstract : The Adaptive Quiz & Exam Engine is a Java-based system developed to make quizzes and examinations easier to conduct and manage.
The system allows students to attend quizzes, answer questions, and view their scores after completing the test.
It also provides an adaptive feature where the difficulty of questions can change depending on the student’s performance.
Teachers can add, update, and manage questions and also check the performance of students.
The project uses Java concepts such as classes, objects, methods, arrays, loops, conditional statements, and file handling to perform different operations.
The system is designed to be simple and easy to use while reducing the effort required for manual evaluation. 
The main aim of the project is to create a basic and efficient quiz system that helps students practice and
evaluate their knowledge while providing practical experience in Java programming.
